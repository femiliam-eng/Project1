# German Credit Data (Biased Training)

This repository contains the **German Credit Data (Biased Training Dataset)** for machine learning and data analysis.

## Description
The dataset is commonly used for:
- Credit risk classification
- Machine learning model training
- Exploratory Data Analysis (EDA)
- Data preprocessing
- Bias and fairness analysis
- Model evaluation

## File
- `german_credit_data_biased_training.csv` — Main dataset used for analysis and model development.

## Purpose
This repository is intended for educational, research, and data science practice purposes.
